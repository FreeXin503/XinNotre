# XinNote 前端视觉升级 — 需求文档

> 冻结日期: 2026-06-04 | 版本: v1.0 | 运行 ID: vibe-run-001

---

## 目标 (Goal)

将 XinNote (OPPO便签导出系统) 前端界面升级为更具沉浸感、高级感和空间舒适度的视觉效果。保留暗色深邃基调，加入微动效提升多巴胺反馈，优化间距和布局使空间更舒适不拥挤。

## 交付物 (Deliverable)

1. 更新后的 `public/css/style.css` — 核心视觉升级
2. 更新后的 `public/index.html` — 布局结构调整（如有需要）
3. 新增 `public/css/animations.css` — 独立动效样式文件

## 约束 (Constraints)

- 不引入任何前端框架（保持纯 HTML/CSS/JS）
- 不修改后端代码 (server/)
- 不改变现有业务功能逻辑
- 保留明/暗双主题切换能力
- 兼容现有 JS 交互逻辑（DOM 结构、class 名保持可识别）

## 验收标准 (Acceptance Criteria)

### AC-1: 深邃感
- [ ] 暗色模式下背景为深黑渐变（`#08080c` → `#131314` 径向渐变）
- [ ] 面板采用玻璃拟态效果（半透明背景 + backdrop-filter blur）
- [ ] 边框使用微弱发光效果替代纯实线边框
- [ ] 可选：加入极低透明度动态光晕

### AC-2: 多巴胺微动效
- [ ] 便签卡片 hover 时有发光边框过渡（0.3s cubic-bezier）
- [ ] AI 对话气泡有入场动画（bubbleIn 保留）
- [ ] 按钮点击有 scale 反馈（active: scale(0.97)）
- [ ] 主题切换有平滑过渡
- [ ] 卡片选中状态有微光脉冲

### AC-3: 空间舒适
- [ ] 侧边栏宽度从 280px 缩减到 260px
- [ ] 便签列表面板从 340px 缩减到 310px
- [ ] 全局 padding/gap 增加 20-30%
- [ ] Header 高度从 60px 增加到 64px
- [ ] 便签卡片间距从 6px 增加到 10px
- [ ] 阅读区正文最大宽度从 820px 缩减到 780px，行高增加到 1.9

### AC-4: 不拥挤
- [ ] 侧边栏分类列表间距增加，每项高度增加
- [ ] 统计卡片改为 2 列布局（原 3 列）
- [ ] 部分低频控件默认折叠

### AC-5: 向后兼容
- [ ] 明亮主题同步调整为清爽版本
- [ ] 现有所有功能正常运作
- [ ] 浏览器视觉效果无异常

## 非目标 (Non-Goals)

- 不改变业务逻辑
- 不修改后端 API
- 不引入 React/Vue 等框架
- 不添加复杂的粒子/3D 效果（可选轻量光晕除外）
- 不改变数据流和状态管理方式

## 开放问题

- 背景动态光晕是否接受？（已默认视为"可选加分项"）
- 是否需要在本次加入音效反馈？（默认：不需要）
