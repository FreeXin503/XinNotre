## 书籍

### 《马云内部讲话》
- **核心论点**: 阿里巴巴内部会议、讲话实录合集，涉及创业文化、价值观、管理与战略布局。强调"客户第一、团队合作、拥抱变化"的核心价值观，以及"因为相信所以看见"的信念体系。
- **出版年份**: 2010（第一版）, 后有续集
- **作者署名**: 阿里巴巴集团（编者），非马云亲笔，系内部讲话整理
- **可信度**: 一手（马云原话转录，经整理汇编）
- **来源**: 公开出版图书，ISBN 978-7-5086-5396-9
- **马云写的/说的 vs 别人总结的**: 马云说的话（一手），但编排由编辑团队完成

### 《马云：未来已来》
- **核心论点**: 马云对未来的判断——从IT时代到DT（数据技术）时代，"新零售、新制造、新金融、新技术、新能源"五新战略。中国将从"世界工厂"变为"世界市场"。
- **出版年份**: 2017
- **作者署名**: 阿里巴巴集团（编者）
- **可信度**: 一手（马云言论整理）
- **来源**: 公开出版图书，ISBN 978-7-5057-4055-8

### 《永不放弃：马云给创业者的50条忠告》
- **核心论点**: 围绕"永不放弃"这一主题，汇编马云关于创业、团队、管理、挫折的50条经验。强调"今天很残酷，明天更残酷，后天很美好，但绝大部分人死在明天晚上"。
- **出版年份**: 2014（可能有多个版本）
- **作者署名**: 马云口述/编著（多版本，编著者不同）
- **可信度**: 二手（多为编者整理，经马云授权但不一定逐字审阅）
- **来源**: 公开出版图书
- **注意**: 市场上有多个同名/类似书名版本，内容质量参差

### 《马云传》《阿里传》《马云正传》等非官方传记
- **核心论点**: 记述马云从屌丝英语老师到中国首富的逆袭历程。强调"三次高考""KFC被拒""创立中国黄页""18罗汉创办阿里""PK eBay"等关键叙事弧线。
- **出版年份**: 2007—2015 多版本
- **作者署名**: 非马云本人，多为财经记者/作家（如刘世英、张刚等）
- **可信度**: 二手（作者调研采访，非马云自述，含演义成分）
- **来源**: 公开出版图书
- **矛盾记录**: 各传记对一些细节（如早期资金数额、具体决策过程）说法不一，建议交叉验证

### 《Alibaba: The House That Jack Ma Built》 (英文)
- **核心论点**: 西方视角解读马云的阿里帝国构建史，深度分析阿里与eBay大战、支付宝VIE争议、IPO过程。强调马云作为"非典型CEO"的领导风格。
- **出版年份**: 2015
- **作者署名**: Duncan Clark（邓肯·克拉克，曾任阿里顾问）
- **可信度**: 二手（作者为阿里早期顾问，有直接接触但非马云本人）
- **来源**: HarperCollins 出版，ISBN 978-0062413406
- **注意**: 作者Duncan Clark与马云有个人接触，可信度高于一般传记

### 《马云：我的世界》（马云自述类，英文版/多语种）
- 注: 马云尚未出版正式的自传（autobiography）。以上所列书籍均为他人整理或传记。

## 系统性长文/演讲

### 1. 2015年达沃斯世界经济论坛 — "哈佛拒绝我10次"
- **场合**: 世界经济论坛年会，与Klaus Schwab对话
- **核心论点**:
  1. 失败是最好的老师——被哈佛拒绝10次、KFC拒绝24选1
  2. 英语改变命运——因尼克松访华产生的英语热，骑自行车给老外当导游
  3. 阿里巴巴不是复制ebay——"学习竞争对手，但从不抄袭"
  4. 关于财富——"超过100万美元，钱就不属于你，是社会对你的信任"
  5. 全球化——"帮助小企业通过互联网参与全球贸易"
- **可信度**: 一手（马云现场发言视频/文字记录）
- **来源**: https://www.weforum.org/stories/2015/09/jack-ma-harvard-rejected-me-10-times/

### 2. 2017年达沃斯世界经济论坛 — 全球化与贸易
- **场合**: 世界经济论坛年会，"对话马云"专场
- **核心论点**:
  1. 全球化不可逆转——"如果你想变得富有，你必须全球化"
  2. 电子商务不是抢工作，而是创造工作
  3. 世界需要新的全球化——"更好的全球化，更包容的全球化"
  4. "一带一路"是创造就业和连接世界的最好机会
  5. AI和自动化不会消灭工作，人类应该做更有创造力的事
- **可信度**: 一手（马云现场发言）
- **来源**: https://www.weforum.org/agenda/2017/04/jack-ma-davos-2017-globalization-world-trade/
- **补充**: 马云在此提出"EWTP"（Electronic World Trade Platform）概念

### 3. 2016年杭州G20 / 乌镇互联网大会 — "五新"概念的提出
- **场合**: 云栖大会（2016年10月）
- **核心论点**: 首次系统提出"五新"概念：
  - **新零售**：线上线下+物流深度融合
  - **新制造**：从B2C到C2B，个性化定制
  - **新金融**：普惠金融，服务80%以前没有被服务的人
  - **新技术**：从IT到DT（数据技术）
  - **新能源**：数据会成为新的生产要素
- **可信度**: 一手（马云现场演讲实录）
- **来源**: 阿里官方/多家主流媒体报道（2016-10-13）

### 4. 2014年阿里巴巴纽交所上市演讲
- **场合**: 纽约证券交易所，阿里IPO（2014年9月19日）
- **核心论点**:
  1. "我们要感谢这个时代、感谢互联网、感谢中国"
  2. 阿里的成功是"小企业信任的力量"
  3. "今天我们收到的不是钱，是信任"
  4. 坚持"客户第一、员工第二、股东第三"
- **可信度**: 一手（全球直播视频/全文）
- **来源**: 纽交所官方/多家国际媒体报道

### 5. 2018年上海外滩金融峰会（争议性演讲）
- **场合**: 2020年10月，上海外滩金融峰会（实际上是2020年，非2018年）
- **核心论点**:
  1. 批评中国金融体系以"典当思维"运营——"银行喜欢当铺"
  2. 抨击巴塞尔协议是"老年俱乐部的规则"
  3. "创新需要冒风险，不要用管理火车站的方式管理金融"
  4. 蚂蚁集团不是金融机构，是科技公司
  5. 呼吁放松监管以鼓励金融创新
- **可信度**: 一手（马云现场演讲视频/文字记录）
- **来源**: 多家媒体报道；此演讲被广泛认为是蚂蚁IPO被叫停的直接导火索
- **矛盾记录**: 此演讲后的监管风暴导致蚂蚁IPO暂停、阿里受反垄断调查。此后马云有较长时间未公开露面。批判者认为马云过度挑战监管边界；支持者认为他道出了金融改革的真实困境。**来源双方立场可能偏颇，需批判性审视。**

### 替补推荐：2026年AI时代教育演讲
- **场合**: 阿里巴巴乡村教师计划（2026年1月线上发言）
- **核心论点**: 教育改革迫在眉睫——"教孩子问几千个好的问题，而不是给同一个正确答案。"应对AI时代的核心是培养创造力和批判性思维。
- **可信度**: 一手
- **来源**: SCMP (https://www.scmp.com/tech/tech-trends/article/3341543/)

## 真信念（≥3次出现）

### 1. "因为相信，所以看见"
- **出现**: 阿里内部讲话、多个公开演讲、达沃斯论坛、马云基金会文档
- **核心**: 强调愿景驱动的逻辑，不是先看见才相信，而是先相信才看见。反常规思维。
- **出现场景**: 创业初期预言互联网改变世界、阿里IPO、退休演讲

### 2. "今天很残酷，明天更残酷，后天很美好"
- **出现**: 创业课堂、励志演讲、大学演讲、媒体采访（超过10次不同场合引用）
- **核心**: 坚持的重要性。"绝大部分人死在明天晚上，看不到后天的太阳。"
- **变化版本**: "很多人倒在了黎明前的黑暗里"

### 3. "让天下没有难做的生意"
- **出现**: 阿里使命宣言、所有公开场合作开场白、马云基金会愿景
- **核心**: 阿里从创立起的使命，也是整个商业生态的核心哲学——赋能中小企业
- **出现场景**: 几乎所有马云和阿里相关的公开场合

### 4. "客户第一，员工第二，股东第三"
- **出现**: 阿里价值观、2014年IPO演讲、内部信、达沃斯、央视采访
- **核心**: 反传统资本主义的股东优先逻辑，强调长期价值由客户驱动
- **矛盾**: 资本市场对此有争议，一些投资者认为这是对股东责任的回避

### 5. "老师的心态"与"教育的意义"
- **出现**: 多次教师相关演讲、乡村教师计划、非洲创业者大赛、退休后的核心活动
- **核心**: 教师经历塑造了他的领导风格。"老师永远希望学生超过自己"。"最好的CEO就是首席教育官。"
- **来源**: 马云基金会、多个演讲

### 6. 关于失败的正面论述
- **出现**: 达沃斯2015、母校演讲、创业分享、清华/港大等高校演讲
- **核心**: 失败是资产不是负债。"我失败了无数次"——三次高考、31次求职被拒、早期融资被30多家VC拒绝
- **逻辑**: 用失败叙事建立共鸣，降低创业者恐惧，强调韧性

## 自创术语

### 1. "让天下没有难做的生意"
- 阿里巴巴使命，核心商业哲学

### 2. "五新" (Five New)
- **新零售** (New Retail) — O2O+物流融合，盒马鲜生是试验田
- **新制造** (New Manufacturing) — C2B定制化，数据驱动
- **新金融** (New Finance) — 普惠金融，蚂蚁集团核心逻辑
- **新技术** (New Technology) — 从IT到DT（Data Technology）
- **新能源** (New Energy) — 数据成为新的能源
- 提出时间: 2016年云栖大会
- **可信度**: 一手
- **来源**: https://www.alizila.com/jack-ma-five-new-frontiers/

### 3. "102年"
- 含义: 阿里要成为跨越三个世纪的公司（1999年成立 → 2101年）
- 逻辑: 20世纪初（1999）→ 21世纪 → 22世纪初，覆盖三个世纪
- 出现场景: 阿里内部文化、IPO路演、18周年庆演讲

### 4. "因为相信所以看见"
- 阿里系最著名的反直觉信念口号
- 与"先看见才相信"的常规思维形成反差

### 5. "EWTP" (Electronic World Trade Platform)
- 2016年提出，马云在全球推广的电子世界贸易平台
- 核心: 帮助中小企业、年轻人参与全球贸易
- 对标: WTO（世界贸易组织）的民间/数字版本
- **来源**: 2016年博鳌亚洲论坛/G20/B20倡议

### 6. "DT时代" (Data Technology Era)
- 替代"IT时代"（Information Technology）
- 核心论点: DT时代以数据驱动、以别人成功为中心（去中心化、赋能），区别于IT时代的以我为中心（管控）

### 7. "湖畔大学"（Hupan University）
- 马云创办的创业者学院（2015-2021年后与政府脱钩）
- 名称来源于阿里创业地湖畔花园小区
- 核心思想: "企业家办教育"

### 8. "996"（争议）
- 马云2019年关于996工作制的内部讲话，后引发巨大争议
- 原话: "能做996是一种巨大的福气...不付出超人的努力，怎么得到超人的回报"
- 矛盾: 此说法与"员工第二、生活工作平衡"的其他表述形成张力。2021年后此观念受到广泛批评。

### 9. 其他反复使用的概念
- "坦克"、"鳄鱼"、"龙虾"（达沃斯演讲中用小动物比喻商业环境）
- "三流的点子+一流的执行" vs "一流的点子+三流的执行"
- "阿里十八罗汉"（创始团队叙事）
- "Horse, farmer, and water" metaphor（达沃斯讲全球化故事）

## 推荐书单/智识谱系

以下为马云在不同场合推荐过或明显受其影响的思想家/书籍:

### 反复推荐的书
1. **《道德经》** — 马云自称读《道德经》三十多年，是其管理哲学核心来源。"上善若水""无为而治"影响他的管理风格。被问到"如果去荒岛带一本书"时回答《道德经》。
2. **《人生》**（路遥） — 18岁时读到，改变了人生。"人生的道路虽然漫长，但紧要处常常只有几步。"
3. **《平凡的世界》**（路遥） — 马云多次提到受路遥影响，让他明白苦难的价值。

### 受影响的商业与思维领袖
4. **金庸** — 阿里的花名文化、武侠文化（"风清扬"是马云在阿里的花名）、"独孤九剑"、"六脉神剑"等阿里价值观命名来源。马云是金庸的超级粉丝。办公室叫"桃花岛"，会议室叫"光明顶"。
5. **杰克·韦尔奇（Jack Welch）** — 通用电气前CEO，影响阿里早期管理文化和人才观。
6. **稻盛和夫** — 日本经营之圣，马云曾专程请教，"敬天爱人"影响马云的企业哲学。阿里曾派高管到京瓷学习。
7. **比尔·盖茨** — 马云在公益领域的对标对象。多次说"比尔·盖茨是我的偶像""在慈善上也还做得不够"。
8. **沃伦·巴菲特** — 马云引用过巴菲特的长期主义理念。

### 受影响的思维方式
9. **毛泽东** — 马云在创业早期使用"农村包围城市"策略（从中小企业切入，对抗eBay等大平台）。"运动战""游击战"等军事思想被引入阿里的商业竞争。阿里内部有"延安整风"式的文化运动。
10. **邓小平** — "黑猫白猫，抓住老鼠就是好猫"的务实主义。马云多次说"感谢改革开放"。

### 信息来源与可信度
- 以上书单分散在马云的达沃斯演讲、央视《开讲啦》、母校演讲（杭师大、港大、清华等）、内部讲话中提及。非一次发布，系交叉整合。
- **可信度**: 一手/二手混合（马云公开提到过这些名字，但"受影响程度"涉及推断）
- **来源**: 公开演讲记录、媒体报道

## 补充：智识矛盾与争议点

1. **"996福报论" vs "员工第二"**: 2019年内部讲话中"能做996是福气"引发舆论风暴，与其一贯宣称的"员工第二"产生矛盾。马云后续澄清但争议未消。
2. **巴塞尔协议批评**: 2020年外滩演讲中批评巴塞尔协议是"老年俱乐部"，但后来蚂蚁被要求按金融控股公司接受监管。言行不一或政策环境变化的典型案例。
3. **全球化立场转变**: 早期全力推崇全球化，后期（2020后）更多强调中国本土市场和"双循环"。外部环境变化导致叙事调整还是真实认知转变？存疑。
4. **技术乐观主义 vs 监管现实**: 马云一贯的技术赋能和金融创新叙事与中国日益收紧的互联网监管现实之间的张力，在其2020年后的低调中表现得最为明显。
