# 张小龙人物时间线

> Agent 6（时间线调研）| 调研日期：2026-06-01

---

## 关键时间线

| 时间 | 事件 | 对我思维的影响 |
|------|------|--------------|
| 1969 | 出生于湖南省洞口县 | — |
| 1988 | 考入华中科技大学（原华中理工大学）电信系 | 大学期间接触计算机，开始编程 |
| 1994 | 研究生毕业 | — |
| 1997 | 独立开发Foxmail 1.0 | 第一次证明"一个人可以做出一款好产品"。Foxmail成为中国最流行的邮件客户端之一 |
| 2000 | Foxmail以1200万元出售给博大公司 | 第一次经历"产品被商业收购" |
| 2005 | Foxmail被腾讯收购，张小龙加入腾讯 | 从独立开发者变成大公司员工 |
| 2010.10 | 微信项目立项（项目代号"微信"） | 腾讯内部多个团队同时做移动社交产品，张小龙团队胜出 |
| 2011.1.21 | 微信1.0发布 | 仅有聊天功能，竞争极其激烈（米聊等先行者） |
| 2011.5 | 微信2.0发布（语音对讲） | 语音功能让微信开始领先 |
| 2011.8 | 微信2.5发布（"查看附近的人"） | 用户突破1000万 |
| 2012.4 | 微信4.0发布（朋友圈） | 从通讯工具变成社交平台。张小龙说"朋友圈是微信最重要的功能" |
| 2012.7 | 微信公众平台上线 | "再小的个体，也有自己的品牌"——这个slogan体现了去中心化理念 |
| 2013.8 | 微信5.0发布（微信支付+表情商店） | 开始商业化探索，但保持克制 |
| 2014.1 | 微信红包上线 | "一个小功能，改变了一个行业"。被马云称为"珍珠港偷袭" |
| 2014.12 | 首次微信公开课Pro演讲 | 第一次系统阐述微信的产品哲学 |
| 2016.1 | 微信公开课Pro提出"用完即走" | 最具争议和辨识度的产品理念 |
| 2017.1 | 微信小程序上线 | "小程序是一个不需要下载的应用"。去中心化策略的极致体现 |
| 2018 | 《财经》罕见深度专访 | 极少数接受个人专访之一 |
| 2019.1 | 微信8周年公开课 | "启动页8年没换，因为初心没变" |
| 2020.1 | 视频号上线 | 比抖音晚4年，但坚持"社交推荐+算法推荐"的混合模式 |
| 2021.1 | 公开课提出"善良比聪明更重要" | 最具价值观色彩的一次演讲 |
| 2022 | 微信生态商业化加速 | 视频号直播带货、广告系统完善 |
| 2023 | 谈AI——"工具是工具，人是主体" | 对AI浪潮的冷静回应 |
| 2024 | 微信公开课谈"慢" | "有些事快不了，该慢就得慢" |
| 2025 | 谈"连接"——"微信的本质是连接，不是内容" | 重新定调微信的底层逻辑 |
| 2026 | 谈"下一个十年"——微信在思考AI时代的形态 | 微信的生态变得更加复杂 |
