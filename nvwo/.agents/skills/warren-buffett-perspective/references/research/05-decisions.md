## 一、成功投资决策

### 1. GEICO 投资 —— 能力圈与耐心的教科书

| 维度 | 内容 |
|------|------|
| **背景** | 1940年代末，巴菲特在哥伦比亚大学求学期间，通过拜访GEICO总部（当时在华盛顿特区）深入了解了这家保险公司。当时GEICO由本杰明·格雷厄姆担任董事会主席，巴菲特在某个周六敲门拜访，得到了副总裁 Lorimer Davidson 长达4小时的讲解。 |
| **决策过程** | **第一阶段（1951年）：** 巴菲特在回到奥马哈后大量推荐GEICO股票，甚至自己投入了约1万美元（占其个人净资产的65%）。他在1952年卖出，获利约50%。<br>**第二阶段（1976年）：** GEICO因承保亏损和过度扩张濒临破产，股价从60美元跌至2美元。巴菲特在此时大举买入，投入约4500万美元。他亲自评估了GEICO的低成本结构这一核心竞争力并未消失。<br>**第三阶段（1995年）：** 伯克希尔以23亿美元收购了GEICO剩余49%的股份，实现全资控股。 |
| **结果** | 1976年的投资到1995年增值超过50倍。GEICO成为伯克希尔保险业务的核心支柱之一，贡献了持续的承保利润和巨额浮存金（float）。 |
| **事后反思** | ✅ **成功**。巴菲特后来在致股东信中称GEICO是他"最爱的投资"之一。关键教训：① 能力圈内才能做出超越市场的判断（保险是他最懂的行业）；② 一家优秀公司暂时陷入困境（而非结构性衰落）是绝佳买入时机；③ 从认识到最终全资收购跨越了45年，展现了极致耐心。 |

### 2. Coca-Cola 投资 —— 品牌护城河的经典

| 维度 | 内容 |
|------|------|
| **背景** | 1980年代，可口可乐在新CEO Roberto Goizueta领导下进行重大改革，出售非核心业务、聚焦碳酸饮料主业。1987年美国股市崩盘后，可口可乐股价处于合理区间。 |
| **决策过程** | 1988年秋天，巴菲特开始秘密买入可口可乐股票。到1989年，伯克希尔持有约7%的可口可乐股份，总成本约10亿美元。他看重的是：① 全球最强的品牌之一，产品简单易懂；② 极深的"护城河"——品牌忠诚度几乎无法复制；③ Goizueta的管理层正在提升资本回报率。 |
| **结果** | 到1993年，5年内股价上涨约5倍。后续十几年持续产生巨额股息回报。截至2022年底，仅股息收入就已超过初始投资成本数倍。1998年曾达到高点，之后经历了长达十年的低迷期，但长期持有仍获得了约10倍的总回报。 |
| **事后反思** | ✅ **成功**（但也有反思空间）。这是巴菲特的"品牌护城河"投资思想的标志性案例。但他在1998年股价过高时没有卖出，导致随后十年回报平庸。巴菲特自我批评说，他应该在估值过高时减持。 |

### 3. 华盛顿邮报 / Graham Holdings 投资

| 维度 | 内容 |
|------|------|
| **背景** | 1973年，华盛顿邮报因涉及"水门事件"报道而名声大噪，但也面临报纸行业的周期性下滑和劳资纠纷。市场对报纸行业前景悲观。 |
| **决策过程** | 巴菲特在1973年以约1060万美元买入华盛顿邮报约10%的股份。他认识该报发行人 Katharine Graham，对管理层极度信任。他认为华盛顿邮报在华盛顿特区拥有近乎垄断的地位，护城河深厚。 |
| **结果** | 到2014年伯克希尔出售该报业集团时（后更名为Graham Holdings），总回报超过120倍（约12亿美元）。这是巴菲特持有时间最长（超过40年）且回报率最高的投资之一。 |
| **事后反思** | ✅ **成功**。体现了：① 对管理层信任的投资模式（巴菲特只投资他信任和尊重的人）；② 拥有"准垄断"地位的企业是极好的长期持有标的；③ 长期持有的复利威力。 |

### 4. 保险浮存金（Float）战略 —— 伯克希尔的引擎

| 维度 | 内容 |
|------|------|
| **背景** | 巴菲特早期在格雷厄姆的保险公司的启发下认识到保险业的独特商业模式。传统上，保险公司先收取保费（客户预付款），后支付理赔款（可能几年后）。这期间积累的资金被称为"浮存金"。 |
| **决策过程** | 1967年，伯克希尔收购了National Indemnity Company，正式进入保险业。随后通过收购GEICO（1976/1995）、General Re（1998）以及建立多家专业保险公司，不断扩大浮存金规模。巴菲特的核心策略：① 专注于获取低成本甚至负成本的浮存金（即承保盈利的保单）；② 用浮存金进行长期股权投资。 |
| **结果** | 伯克希尔的保险浮存金从1970年的约4000万美元增长到2023年的约1690亿美元。更关键的是，大部分时期的综合成本率低于100%（承保本身盈利），这意味着巴菲特是在"别人付费让他拿钱去投资"。 |
| **事后反思** | ✅ **成功**。这是伯克希尔超越绝大多数投资机构的根本原因。浮存金战略让巴菲特拥有了比任何基金经理都更稳定的"长期资本"，永远不会遭遇"赎回压力"。精算与投资的双轮驱动是伯克希尔模式的护城河。 |

### 5. 买入 Apple —— 从"不投科技"到最大持仓的转变

| 维度 | 内容 |
|------|------|
| **背景** | 巴菲特长期回避科技股，称自己"不理解科技公司"。但在2016年，伯克希尔开始买入Apple股票。当时Apple已经是一个成熟的消费品牌，而非早期的科技冒险者。 |
| **决策过程** | 2016年第一季度，伯克希尔首次买入约10亿美元Apple股票。到2018年，持仓增至约250亿美元。巴菲特的逻辑转变：① Apple不是科技公司，而是拥有极强品牌忠诚度的消费品公司；② iOS生态系统形成了极高的用户粘性（转换成本极高）；③ 强大的现金流和资本回报计划（回购+分红）。 |
| **结果** | 到2023年底，Apple持仓市值超过1500亿美元，占伯克希尔投资组合的约45-50%，成为其最大持股。从2016年到2024年，回报超过5倍。 |
| **事后反思** | ✅ **成功**。这是巴菲特"进化能力"的标志性案例。他虽然长期回避科技股，但当Apple展现出消费品护城河特征时，他能打破自己的规则。Todd Combs 和 Ted Weschler（两位投资副手）在最初推荐了Apple，但巴菲特亲自做了最终决策。 |

### 6. 收购 BNSF 铁路 —— 重资产投资的转变

| 维度 | 内容 |
|------|------|
| **背景** | 巴菲特长期偏好轻资产、高回报的商业模式，对重资产行业（铁路、公用事业）持怀疑态度。但2008年金融危机后，BNSF铁路公司股价大幅下跌。 |
| **决策过程** | 2007年，伯克希尔首次购入BNSF股票（当时约占总股本10%）。2009年11月，巴菲特宣布以340亿美元收购BNSF剩余77%股权（包括承担债务的总交易额约440亿美元）。这是伯克希尔当时最大的一笔收购。他看重的因素：① 美国经济离不开铁路运输，BNSF在西部拥有垄断性线路；② 铁路比卡车更环保、更省油，长期竞争力上升；③ 尽管是重资产，但BNSF拥有定价权和稳定的现金流。 |
| **结果** | BNSF成为伯克希尔旗下最重要的非保险业务之一，每年贡献约50-60亿美元盈利。这体现了巴菲特从"纯资产配置者"向"实业运营者"的转变。 |
| **事后反思** | ✅ **成功**。收购时很多人认为价格过高（约15倍EBITDA），但后续回报证明这是明智之举。关键教训：① 即使巴菲特的原则（"远离重资产"）也可以在特殊情况下改变；② 拥有定价权的垄断性基础设施是优秀的长期资产。 |

### 7. 比亚迪投资 —— 新兴市场的经典一战

| 维度 | 内容 |
|------|------|
| **背景** | 2008年，比亚迪还是一家不太知名的中国电池和汽车制造商。芒格向巴菲特推荐了比亚迪和他的创始人王传福，称王传福是"爱迪生和韦尔奇的结合体"。 |
| **决策过程** | 2008年9月，伯克希尔旗下 MidAmerican Energy（现伯克希尔能源）以2.3亿美元买入比亚迪10%股份（约2.25亿股）。当时比亚迪正面临电动车行业发展的巨大不确定性。巴菲特的投资逻辑：① 对王传福能力的高度信任；② 比亚迪在电池技术上的积累；③ 中国电动车市场的巨大潜力。 |
| **结果** | 到2022年，这笔投资增值超过30倍（最高时超过40倍）。伯克希尔从2022年8月开始减持，到2024年已减持过半，套现大量利润。 |
| **事后反思** | ✅ **成功**。这是芒格推动巴菲特的典型案例，也是伯克希尔在中国最成功的投资。减持时机值得研究——巴菲特在比亚迪股价仍然强势时开始减持，避免了后续可能的回撤。 |

### 8. 日本五大商社投资 —— 晚年的精彩一步

| 维度 | 内容 |
|------|------|
| **背景** | 2020年8月，巴菲特宣布伯克希尔已购入日本五大商社（伊藤忠、丸红、三菱、三井、住友）各约5%的股份。这是巴菲特的罕见非美国市场大额投资。 |
| **决策过程** | 在接近90岁高龄时，巴菲特做出了这一长期投资决策。他看重的因素：① 五大商社与伯克希尔类似——它们是拥有多元化业务的巨型集团；② 估值极低（约5-6倍PE），分红稳定（股息率约4-5%）；③ 它们在全球资源和大宗商品领域拥有深厚的网络；④ 伯克希尔发行低息日元债券融资，实现了近乎无风险的套利（日元融资成本约0.5%，股息率约5%）。 |
| **结果** | 到2024年，五大商社股价普遍翻倍以上。伯克希尔将持股比例增至约7-9%，并计划长期持有。 |
| **事后反思** | ✅ **成功**。这笔投资展现了巴菲特的几个特点：① 即使晚年仍有能力学习新市场；② 利用低息日元债券进行套利是天才般的财务工程；③ 选择与伯克希尔商业模式相似的公司，再次体现了"能力圈"原则。 |

## 二、决策失败案例

### 9. Dexter Shoe —— 巴菲特自认的最大错误

| 维度 | 内容 |
|------|------|
| **背景** | 1993年，伯克希尔以约4.33亿美元收购Dexter Shoe。这是一家美国中高端鞋类制造商。巴菲特看好其品牌地位和管理层。 |
| **决策过程** | 巴菲特对Dexter管理层非常信任（尤其是创始人Harold Alfond），且认为美国制鞋业有稳定的护城河。但他犯了一个致命的错误：他选择了用伯克希尔股票来支付收购，而不是现金。 |
| **结果** | 亚洲低成本制鞋业的竞争迅速摧毁了Dexter的竞争力。到2000年代初，Dexter几乎一文不值。更大的问题是：巴菲特是用伯克希尔股票支付的，而这些股票如果持有到今天，价值超过百亿美元。 |
| **事后反思** | ❌ **失败**。巴菲特在2007年致股东信中将其列为"一生中最大的错误"。几个因素：① 对行业竞争格局的判断失误（没有预见到全球化对低端制造业的冲击）；② 用股票收购加剧了损失（相当于用优质公司的股份换了劣质资产）；③ 对管理层的过度信任导致缺乏尽职调查的深入。 |

### 10. US Air 投资 —— 对周期性行业的教训

| 维度 | 内容 |
|------|------|
| **背景** | 1989年，伯克希尔以3.58亿美元买入US Air（全美航空）优先股。当时航空业竞争激烈，盈利能力普遍不佳。 |
| **决策过程** | 巴菲特承认他犯了"冲动"的错误——他因不满行业整合趋势而逆势买入。他看中了US Air在东部航线的优势位置，但也知道航空业是"死亡竞争"。他设计优先股条款来保护下行风险。 |
| **结果** | 1990-1994年，US Air持续巨亏，一度濒临破产。巴菲特差点血本无归。幸运的是，US Air最终扭亏为盈并赎回了优先股，巴菲特勉强保本并获得少量利息。 |
| **事后反思** | ❌ **失败**。巴菲特多次引用US Air的教训，后来在航空股上反复吃亏。他在1990年股东大会上说："如果你是一个有远见的人在莱特兄弟那个年代就应该把莱特兄弟打下来。"2020年疫情期间，他清仓所有航空股并承认自己判断错了航空业的复苏前景。总结：航空业固定成本高、产品同质化、工会强势、竞争激烈，几乎不具备护城河。 |

### 11. Tesco 投资 —— 国际化投资的陷阱

| 维度 | 内容 |
|------|------|
| **背景** | 2012年，伯克希尔开始买入英国最大零售商Tesco的股票。巴菲特认为Tesco拥有强大的英国零售市场份额和管理能力。 |
| **决策过程** | 巴菲特在2006年曾小规模投资Tesco并获利退出。2012年，他重新大举买入，到2013年初伯克希尔持有Tesco约5%的股份（约4.7亿美元）。 |
| **结果** | 2013年开始，Tesco爆出会计丑闻，市场份额被Aldi和Lidl等德国折扣零售商侵蚀，盈利大幅下滑。2014年，巴菲特清仓了大部分仓位，亏损约5亿美元。他在2015年致股东信中称这是"因不够专注而犯的大错"。 |
| **事后反思** | ❌ **失败**。教训：① 零售业变化极快，过去的成功不保证未来；② 威廉·桑代克（投资经理）曾指出——巴菲特没有像通常那样仔细阅读Tesco的财报，错过了早期警告信号；③ 国际投资的信息劣势明显，即使是巴菲特也难以及时发现海外公司的财务问题。 |

### 12. General Re 的衍生品问题 —— 风险控制的警示

| 维度 | 内容 |
|------|------|
| **背景** | 1998年，伯克希尔以220亿美元收购再保险公司General Re。General Re旗下拥有一支衍生品交易团队，涉及大量复杂的金融衍生品合约。 |
| **决策过程** | 巴菲特在收购前知道衍生品业务的存在，但低估了其复杂性和潜在风险。他后来发现General Re的衍生品合约存在巨大的"尾部风险"（极小概率但灾难性的损失可能）。 |
| **结果** | 巴菲特花了数年时间以巨大成本（超过4亿美元）关闭General Re的衍生品业务。期间这些合约几次几乎引发巨额亏损。巴菲特在2003年致股东信中用了大量篇幅批评衍生品，称它们是"大规模杀伤性金融武器"。 |
| **事后反思** | ❌ **失败**（但被及时纠正）。这强化了巴菲特对复杂金融工具的极度厌恶。伯克希尔此后几乎完全回避了衍生品业务（除了为保险目的使用的少量合约）。教训：收购时对目标公司的隐性业务（尤其是金融衍生品）必须做详尽尽调。 |

## 三、重大组织决策

### 13. 与查理·芒格合作关系的形成

| 维度 | 内容 |
|------|------|
| **背景** | 1959年，29岁的巴菲特在奥马哈的一次晚宴上遇到了35岁的芒格。两人同为奥马哈人，芒格当时是洛杉矶的一名律师。 |
| **决策过程** | 两人一见如故，在电话和信件中进行了长时间的投资讨论。直到1975年，芒格终于决定完全投入投资事业，与巴菲特展开正式合作。芒格从律师转为投资经理，后来成为伯克希尔的副董事长。 |
| **结果** | 芒格对巴菲特的投资思想产生了根本性影响，推动他从"雪茄烟蒂投资法"（以极低价格买入平庸公司）转向"以合理价格买入优质企业"。伯克希尔之所以能成为今天的伯克希尔，很大程度上要归功于芒格的思想影响。 |
| **事后反思** | ✅ **成功**。巴菲特多次承认芒格让他"从猿进化成了人"。这段合作关系是现代商业史上最成功的合伙关系之一，持续了超过60年直到芒格2023年去世。 |

### 14. 伯克希尔的起源：从纺织厂到巨型集团

| 维度 | 内容 |
|------|------|
| **背景** | 1962年，巴菲特开始在公开市场上买入一家陷入困境的新英格兰纺织公司——伯克希尔·哈撒韦的股票。这家公司由Horace Hathaway和伯克希尔精细纺织公司合并而成。 |
| **决策过程** | 1965年，通过Buffett Partnership以约1400万美元控制了伯克希尔。巴菲特最初计划像以前的投资一样，"解套"后卖掉。但公司管理层（尤其是Stanley Kaplan）试图以低价回购股票激怒了巴菲特，他决定全面收购并更换管理层。 |
| **结果** | 纺织业务在1985年彻底关闭。但伯克希尔本身成为了一个"空壳"，巴菲特将National Indemnity等保险公司的股权注入其中，伯克希尔从此转型为保险控股公司，进而成为全球最大的综合性集团之一。 |
| **事后反思** | 混合结果。如果巴菲特没有因为愤怒而接管伯克希尔，他可能会走另一条路。但这项决策最终成就了今天市值超过8000亿美元的伯克希尔帝国。巴菲特幽默地说这是"他花了1400万美元学到的教训"——不要因为愤怒而做投资决策。 |

### 15. 巴菲特选择接班人的过程

| 维度 | 内容 |
|------|------|
| **背景** | 巴菲特从1990年代开始思考"谁能在伯克希尔失去他之后仍保持其文化"。这一问题持续了20多年。 |
| **决策过程** | **第一阶段（1979-1990s）：** Lou Simpson（GEICO的投资主管）被视为可能的接班人，但他的投资范围太窄。<br>**第二阶段（2000s）：** David Sokol（MidAmerican Energy CEO）成为接班人的领先人选，但他2011年因内幕交易丑闻辞职。<br>**第三阶段（2010s）：** 两位对冲基金经理Todd Combs和Ted Weschler被聘请为投资副手，被视为"双人接班"模式的可能。<br>**最终阶段（2020s）：** 巴菲特明确宣布Greg Abel（伯克希尔能源CEO）为接班人，主管运营；而投资组合将由Combs和Weschler共同管理。 |
| **结果** | Greg Abel被公认为是合适的接班人。他了解伯克希尔的文化，擅长资本配置，且深得巴菲特的信任。 |
| **事后反思** | ✅ **成功**。巴菲特用了25年精心设计和调整接班方案，避免了大多数企业"突然换帅"的危机。Abel的逐步上位确保了文化传承。 |

### 16. 不分红不拆股的政策与A股超高单价

| 维度 | 内容 |
|------|------|
| **背景** | 大多数上市公司定期分红、拆股以降低股价，吸引散户投资者。伯克希尔自1967年以来从未派发现金股息。 |
| **决策过程** | 巴菲特坚持：① 不分红——他认为保留盈利可以创造比股东自己投资更高的回报；② 不拆股——高股价吸引了长期投资者而非短线交易者。1965年，伯克希尔A股股价约15美元；到2024年，A股价格超过60万美元（全球单价最高的股票）。1996年，巴菲特创造了B股（初始价格为A股的1/30），以低成本满足小投资者的需求——但即使B股也从不拆股。 |
| **结果** | 这一政策维持了半个多世纪。直到2024年，巴菲特开始改变策略，伯克希尔开始回购股票（这是另一种回馈股东的方式，且税收效率更高）。 |
| **事后反思** | ✅ **成功**（但近年来有所调整）。巴菲特证明了不分红可以创造更大的股东价值。近年来伯克希尔开始回购（这也是一种"分红"方式，只是形式不同），展现了他对资本配置的灵活性。 |

## 四、人生重大转折

### 17. 师从本杰明·格雷厄姆 —— 投资哲学的奠基

| 维度 | 内容 |
|------|------|
| **背景** | 1950年，19岁的巴菲特在阅读了格雷厄姆的《聪明的投资者》后深受启发，决定前往哥伦比亚商学院师从格雷厄姆。 |
| **决策过程** | 巴菲特是格雷厄姆班上最活跃的学生之一，毕业后多次请求到格雷厄姆的合伙公司工作。最初被拒绝，后来在1954年终于被聘为分析师。他在格雷厄姆那里学到了"安全边际"概念和以统计数字为基础的价值投资方法。 |
| **结果** | 格雷厄姆的投资方法（寻找"烟蒂股"——股价低于净运营资本的便宜公司）成为巴菲特早期的投资框架。虽然后来被芒格修正，但"安全边际"和"市场先生"的概念贯穿了巴菲特的一生。 |
| **事后反思** | ✅ **成功**。如果没有师从格雷厄姆，巴菲特可能不会形成系统性的投资框架。但巴菲特后来的成功也在于他超越了格雷厄姆——格雷厄姆只买便宜的，不买好的；巴菲特学习了芒格，愿意为好企业支付合理价格。 |

### 18. 成立 Buffett Partnership 与解散（1956-1969）

| 维度 | 内容 |
|------|------|
| **背景** | 1956年，25岁的巴菲特在奥马哈创立了Buffett Partnership, Ltd.（巴菲特合伙有限公司）。公司由7个有限合伙人（包括他的家人和朋友）出资10.5万美元，巴菲特自己出资100美元。 |
| **决策过程** | 合伙公司采取收费结构：年回报6%以内不收任何费用，超过6%的部分收取25%的业绩分成。这个结构让巴菲特可以专注投资，同时激励他的超额回报。合伙公司取得了令人难以置信的业绩：从1956年到1969年，扣除费用后年化回报约30%（同期道琼斯指数年化约9%）。 |
| **结果** | 1969年，巴菲特做出一个惊人的决定：解散合伙公司。他认为市场已极度高估，找不到有吸引力的投资机会。他不愿为了管理费而投资劣质标的。他将合伙公司的资产分配给合伙人——其中包括了伯克希尔·哈撒韦的股票。 |
| **事后反思** | ✅ **成功**。解散合伙公司是道德勇气和纪律的完美体现。大多数基金经理在高估市场中继续收取管理费，但巴菲特选择了对投资人负责。这奠定了他在投资界的声誉和道德威望。 |

### 19. 芒格的影响：从"雪茄烟蒂"到"优质企业"的思想飞跃

| 维度 | 内容 |
|------|------|
| **背景** | 巴菲特最初严格遵循格雷厄姆的"雪茄烟蒂投资法"（cigar butt approach）——寻找"还剩最后一口"的廉价股票，以极低价格买入，赚取微薄利润后卖出。 |
| **决策过程** | 芒格的影响体现在几个关键点上：① 1960年代末，芒格说服巴菲特以远高于账面价值的价格收购喜诗糖果（See's Candies），这是巴菲特第一次为"品牌和商誉"付费；② 芒格不断灌输"以合理价格买入伟大企业远胜于以伟大价格买入平庸企业"的理念；③ 这一思想转变影响了后来所有伯克希尔的重要投资——从可口可乐到BNSF。 |
| **结果** | 伯克希尔从一家"清算式的烟蒂投资组合"转变为"永续持有的优质企业集合"。如果没有这一转变，伯克希尔可能只是另一家清算基金，而非今天的商业帝国。 |
| **事后反思** | ✅ **成功**。这是巴菲特投资哲学中最重要的转折点。巴菲特坦诚说："查理让我从猿进化成了人。"思想转变的核心：从买"便宜"到买"好"。 |

### 20. 承诺捐出 99% 的财产（Giving Pledge）

| 维度 | 内容 |
|------|------|
| **背景** | 2006年，巴菲特宣布将其85%的伯克希尔股票逐步捐赠给比尔及梅琳达·盖茨基金会等慈善机构。2010年，他与比尔·盖茨共同发起"捐赠誓言"（Giving Pledge），号召全球亿万富翁承诺捐出大部分财富。 |
| **决策过程** | 巴菲特的承诺分几步实现：① 每年7月将部分B股转换为A股后捐赠给基金会；② 他明确表示"留给孩子足够的钱去做任何事，但不至于多到什么都不做"；③ 到2024年，他已捐出超过580亿美元（约占其持有伯克希尔股票的一半以上）。 |
| **结果** | 巴菲特成为全球慈善捐赠最多的个人之一。截至2024年，他仍在世时已经开始执行捐赠计划，而不像其他慈善家那样等去世后才设立基金。 |
| **事后反思** | ✅ **成功**（从社会影响力角度）。巴菲特说："我出生时抽中了'卵巢彩票'"——他感恩自己在合适的时间和地点出生。他的捐赠承诺将金钱问题与家族继承问题分开，这种方式被许多企业家效仿。 |

## 关键主题

1. **进化能力**：巴菲特的思想不断进化——从格雷厄姆的"烟蒂股"到芒格主张的"优质企业"，从"不投科技"到重仓Apple，从"轻资产偏好"到收购BNSF——他始终保持学习和改变的能力。

2. **纪律与耐心**：每一次巨大成功的背后都是极度的纪律——等待正确的价格、持有足够长的时间（GEICO跨越45年、华盛顿邮报持有40年）。

3. **诚实面对失败**：巴菲特以罕见的坦率公开剖析自己的错误（Dexter Shoe的股票收购、US Air的冲动投资），这种诚实是他获得市场长期信任的基础。

4. **能力圈原则**：几乎所有重大失败（Dexter Shoe、Tesco）都可归结为走出了能力圈；几乎所有重大成功（GEICO、Coca-Cola、Apple）都在能力圈内。

5. **资本配置的创造性**：从浮存金战略到日元债券套利，巴菲特展示了超越"选股"的资本配置智慧。
