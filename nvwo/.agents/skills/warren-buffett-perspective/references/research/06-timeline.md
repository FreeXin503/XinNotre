# Warren Buffett 完整时间线（1930-2026）

> 本文档由 Agent 6（人物时间线）梳理，覆盖从出生到2026年的关键里程碑。

---

## 早期生涯（1930-1950）

| 时间 | 事件 | 为什么重要 |
|------|------|-----------|
| **1930.8.30** | 出生于内布拉斯加州奥马哈 | 奥马哈成为其一生标签——"奥马哈先知" |
| **1942年（11岁）** | 买入人生第一支股票：Cities Service Preferred（3股，$38/股） | 投资生涯的起点；后来股价下跌后割肉卖出，却看着它涨到$200，留下终身教训 |
| **1944年（14岁）** | 用$1,200储蓄购买40英亩农场出租给佃农 | 少年时代已展现资本配置天赋 |
| **1947年** | 高中毕业，进入宾夕法尼亚大学沃顿商学院 | 两年后因不喜欢转学至内布拉斯加大学林肯分校 |
| **1950年** | 申请哈佛商学院被拒；转而进入哥伦比亚大学商学院，师从Benjamin Graham | 被拒是低估的祝福——Graham的"价值投资"体系塑造了Buffett一生框架 |

## 师从Graham与创业期（1951-1969）

| 时间 | 事件 | 为什么重要 |
|------|------|-----------|
| **1951年** | 发现Graham在GEICO董事会；周末坐火车到华盛顿敲GEICO大门，与副总裁Lorimer Davidson畅谈数小时 | 首次接触保险浮存金（float）概念，成为日后Berkshire的核心竞争优势 |
| **1951-1954年** | 在父亲的公司Buffett-Falk & Co.做股票销售员；同时夜晚在University of Nebraska-Omaha教授"投资原理"课程 | 学生平均年龄是他两倍；Dale Carnegie公开演讲课改变了他的人生 |
| **1954-1956年** | 加入Graham-Newman Corp做证券分析师（年薪$12,000） | 近距离学习Graham的"捡烟蒂"（cigar butt）投资法 |
| **1956年（25岁）** | 回到奥马哈，成立Buffett Partnership Ltd.（起始资金$10万，其中$100来自他自己） | 投资合伙企业的起点；至1969年复合年化收益率超30% |
| **1959年** | 在奥马哈俱乐部的一场午餐中遇到Charlie Munger | 一生中最重要的人际关系；Munger后来推动他从"买便宜货"转向"合理价格买好公司" |
| **1962年** | 成为百万富翁；合并多个合伙公司为统一实体Buffett Partnership, Ltd. | 个人资产超$100万；开始买入濒临倒闭的纺织公司Berkshire Hathaway（$7.60/股） |
| **1965年** | 因Stanton违背回购口头承诺，Buffett大怒买入更多股份并控制Berkshire Hathaway | 这是"一生最大的投资错误"——为报复买了一家夕阳产业，代价是2000亿美元的复利损失 |
| **1967年** | Berkshire收购National Indemnity Company（$860万） | 从纺织转型保险的起点，此后保险浮存金成为投资引擎 |
| **1969年** | 解散Buffett Partnership Ltd.，将资产（含Berkshire股票）分配给合伙人 | 正值市场狂热时离场，展现了逆周期能力 |

## Berkshire帝国成型（1970-1999）

| 时间 | 事件 | 为什么重要 |
|------|------|-----------|
| **1972年** | Berkshire以$2500万收购See's Candies | 标志性转折点：从"烟蒂股"转向"优质企业合理价格"；到2019年这笔投资回报超$20亿（8000%） |
| **1973年** | 开始买入华盛顿邮报公司股票 | 与Katharine Graham结为挚友；投资回报超百倍 |
| **1976-1980年** | GEICO濒临破产，股价暴跌；Buffett大举买入 | 逆向投资的经典案例；Berkshire后来全资拥有GEICO，成为核心现金牛 |
| **1988年** | 大举买入可口可乐股票（$10.2亿买入7%） | 最著名的长期持有案例之一；至今仍是Berkshire核心持仓，体现品牌护城河投资哲学 |
| **1990-1991年** | Salomon Brothers国债投标丑闻；Buffett临危受命担任临时董事长 | 展示危机管理能力；Salomon因他的介入免于刑事起诉和倒闭 |
| **1996年** | 发行Berkshire B类股（1/30 A类股价值，1/200投票权） | 为阻止类似Unit Trust产品；降低散户买入门槛 |
| **1998年** | 以$220亿收购General Re（再保险公司） | 后来被证明是失败交易——衍生品头寸问题重重；被迫大幅减记 |
| **1999年** | 互联网泡沫中Berkshire股价下跌20%，媒体称Buffett"过时了" | 市场风格切换时价值投资者被嘲笑；为2000年科技泡沫破裂后回归正名埋下伏笔 |

## 成熟期与危机应对（2000-2015）

| 时间 | 事件 | 为什么重要 |
|------|------|-----------|
| **2000年** | 互联网泡沫破裂；科技股暴跌，Berkshire上涨26.6% | "当潮水退去才知道谁在裸泳"——价值投资回归 |
| **2006年** | 宣布将85%财富捐给五家基金会，最大部分给Bill & Melinda Gates Foundation | 史上最大慈善捐赠（约$370亿）；开启慈善资本主义新篇章 |
| **2008年金融危机** | 为Goldman Sachs注资$50亿（10%优先股+认股权证）；为GE注入$30亿；公开发表"Buy American. I am." | 以"白衣骑士"身份救市；展示危机中贪婪买入的能力；Goldman交易最终获利约$37亿 |
| **2008年** | 超越Bill Gates成为世界首富（Forbes: $620亿） | 投资生涯最高荣誉之一 |
| **2010年** | 发起Giving Pledge（与Bill Gates、Melinda French Gates共同发起） | 推动全球超级富豪承诺捐出一半以上财富；已有250+签署人 |
| **2010年** | 以$260亿收购BNSF铁路剩余77%股份（Berkshire史上最大收购） | 对美国的"全仓押注"——铁路是经济命脉；此后BNSF贡献稳定现金流 |
| **2011年** | 向Bank of America投资$50亿（6%优先股+认股权证） | 金融危机后连续第二次"救银行"；最终获利超$120亿 |
| **2015年** | 以$372亿收购Precision Castparts（精密铸件） | Berkshire史上最大收购；2020年减记约$100亿——承认"付了太多钱" |

## 技术股转向与后Munger时代（2016-2024）

| 时间 | 事件 | 为什么重要 |
|------|------|-----------|
| **2016年Q1** | 开始买入Apple股票（最初持仓$10亿） | 从"从不投科技股"到"Apple是消费品公司"的思想转身；最终持仓超$1500亿，成为Berkshire最大单一持仓 |
| **2018年** | 清仓IBM，大幅增持Apple | 承认IBM是错误；将重心转向Apple——体现从小打小闹到重仓巨头的进化 |
| **2020年4月** | 新冠疫情中清仓全部航空股（Delta、United、American、Southwest） | 罕见地公开认错并止损；"世界变了，我不想赌航空业的恢复" |
| **2022年Q1起** | 大幅增持西方石油（Occidental Petroleum） | 能源超级周期赌注；持仓超25%成为最大股东之一 |
| **2022-2023年** | 持续增持日本五大商社（伊藤忠、三菱、三井、住友、丸红） | 罕见的跨国集中投资；伯克希尔发行日元债券对冲汇率风险，被誉为大师级套利 |
| **2023.11.28** | Charlie Munger去世（享年99岁） | 60年搭档的终结；Buffett说"Berkshire的架构是Charlie设计的" |
| **2024年Q2** | 减持近50% Apple持仓（套现$755亿），现金储备增至$2770亿 | 引发市场对Apple和美股整体估值过高的猜测；现金创历史新高 |
| **2024年8月** | Berkshire Hathaway市值突破$1万亿 | 首个非科技公司达到万亿美元市值；A股价格历史性突破$70万/股 |
| **2024年Q4** | 继续减持Apple，清仓S&P 500 ETF；现金储备增至$3342亿 | 史上最大现金堆；市场广泛解读为Buffett极度谨慎的信号 |

## 思想转折点汇总

### 1. 从"烟蒂股"到"合理价格买好企业"
- **触发点**：Munger的影响 + See's Candies的惊人回报
- **转变时间**：约1972年收购See's之后
- **关键结果**："以合理的价格买入一家伟大的企业，远胜过以便宜的价格买入一家平庸的企业"

### 2. 从"不投科技"到投资Apple
- **触发点**：Tim Cook的领导力 + Apple的消费者品牌属性（生态黏性、定价权）
- **转变时间**：2016年首次买入Apple
- **关键结果**：Apple成为Berkshire最大的持仓（一度占投资组合的~50%）

### 3. 从收购到回购
- **旧模式**：用保险浮存金收购整个企业
- **新模式**：2011年后大规模股票回购（特别是2018年后）
- **逻辑**：当股价低于内在价值时，回购是最佳资本配置方式

### 4. 从囤积现金到增大配置
- **旧策略**：手持大量现金等待"大象级"收购
- **当前困境**：2023-2026年现金持续增创历史新高，但缺乏大规模收购标的（估值过高、反垄断收紧）
- **Abel时代的转变**：开始配置中小型收购（Taylor Morrison、OxyChem）+ 持续回购 + 日本商社
