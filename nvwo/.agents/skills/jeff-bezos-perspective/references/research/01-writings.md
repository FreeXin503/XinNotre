# 著作与系统思考（Agent 1）

## Amazon 致股东信（24 封，1997—2020）

**时间跨度**：1997 年（IPO 当年）至 2020 年（最后一份）

### 核心主题逐年演变

| 年份 | 核心主题 | 关键概念 |
|------|---------|---------|
| 1997 | 长期主义宣言 | "It's All About the Long Term"，确立 8 条经营原则 |
| 1998 | 对客户保持恐惧 | "Always be afraid of your customers" |
| 1999 | 基础设施红利 | 网络带宽等基础设施每年在改善 |
| 2000 | 现金护城河 | 互联网泡沫后的生存策略 |
| 2001 | FCF 才是真指标 | 自由现金流而非 GAAP 利润 |
| 2002 | 固定成本杠杆 | 超过盈亏平衡点后每单利润极高 |
| 2003 | 所有者 vs 租户 | 长期思维来自所有权心态 |
| 2004 | FCF 北极星 | 现金流的现值才是股票价值 |
| 2005 | 数据 vs 判断 | 有些决策数据给答案，有些靠判断 |
| 2006 | 培育幼苗 | 新业务不能用成熟业务标准衡量 |
| 2007 | 传教士 vs 雇佣兵 | Missionaries build better products |
| 2008 | 从客户出发 | Working backwards not forward from skills |
| 2009 | 控制输入 | 关注可控的输入变量，输出自然来 |
| 2010 | 内部工具变平台 | AWS 模式 |
| 2011 | 自助平台 | 自服务释放创新 |
| 2012 | 主动惊喜 | 在客户提出之前就满足需求 |
| 2013 | 飞轮效应 | 循环加速的增长模型 |
| 2014 | 非对称押注 | 有上限风险、无上限回报的赌注 |
| 2015 | Type 1 vs Type 2 | 不可逆 vs 可逆决策的区分 |
| 2016 | Day 2 即死亡 | 停滞 → 无关 → 痛苦 → 死亡 |
| 2017 | 高门槛可传授 | 知道什么是好 + 真实期望 |
| 2018 | 赋能竞争对手 | 开放平台让对手也成功 |
| 2019 | 刻意流浪 | 最好的发明来自非计划探索 |
| 2020 | 创造多于消耗 | 最后一份，更个人化、"Be kind" |

### 自创术语与概念
- **Day 1**：永远保持创业心态（Day 1 四大要素：客户至上、抵制代理、拥抱趋势、高速度决策）
- **Flywheel（飞轮）**：业务各环节的自我强化循环
- **Regret Minimization Framework**：投射到 80 岁，选后悔最少的
- **Type 1 / Type 2 Decisions**：一扇门 vs 两扇门
- **Disagree and Commit**：不同意见不阻碍前进
- **Working Backwards**：从客户需求反推产品
- **The Empty Chair**：会议室里客户的席位
- **Two-Pizza Team**：两个披萨能喂饱的团队规模
- **Six-Page Memo vs PowerPoint**：叙事优于点阵
- **High Standards are Teachable**：高标准可传授

### 推荐书单（揭示智识谱系）
- 《The Remains of the Day》（石黑一雄）—— 书中对其影响极大
- 《Sam Walton: Made in America》—— 零售业的启蒙
- 《The Black Swan》（塔勒布）—— 对不确定性的理解
- 《Built to Last》（Collins）—— 基业长青的思考
- 《The Innovator's Dilemma》（Christensen）—— 颠覆式创新
