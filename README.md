# OPPO 便签极速导出与 AI 灵魂对话预览系统 (v3.5)

本系统由 **Xin's Software Dev All-Stars (开发天团)** 专为您量身打造。这是一个 **100% 纯前端、无服务端、本地解析** 的超安全、高隐私便签备份、离线阅读与 **AI 个人生命历史学家** 对话套件。

---

## 📂 项目结构与核心模块

*   `oppo_notes_exporter.user.js`：**【双通道极速网络拦截脚本】**。核心 Tampermonkey (油猴) 脚本，支持大小写混淆、驼峰/蛇形命名自适应，在网络底层拦截 API 响应，一秒抓取 1600+ 全量便签。
*   `preview.html`：**【高级 Markdown 本地可视化预览与 AI 生命回顾对话系统】**。一个独立的单页面 Web 应用（SPA），采用玻璃拟态暗黑美学。
    *   **📖 便签阅览**：支持实时分类过滤、本地毫秒级全文模糊检索及精美 Markdown 渲染，附带 200ms 本地 ZIP 重新分目录无损打包。
    *   **🧠 灵魂对话**：**【顶级重磅更新】**集成 DeepSeek 官方大模型接口与**本地 RAG 混合搜索引擎**。自动检索您的日记，为您深度回顾、梳理和剖析过去几年的心路情感起伏与事业技术成长轨迹。
*   `notes_data.js`：**【免手动上传黑科技】**。已自动将您导出的 **25MB** 全量便签数据预装载至此文件中。您无需拖拽或上传任何文件，双击打开 `preview.html` 即可秒级展示全部 1600+ 篇便签与统计画像！
*   `oppo_notes_export_2026-06-01 (7).json`：您成功导出的 25MB 全量便签原始数据文件。

## 🚀 灵魂对话 AI 导师（DeepSeek API 集成）

为了帮助您回顾过去几年的感悟和经历，我们在可视化预览页面右侧重磅添加了 **“🧠 灵魂对话”** 选项卡。

### 1. 核心 AI 机制与功能
*   **本地 RAG 混合检索引擎**：当您向 AI 提问时，系统会采用纯本地的高性能分词词频匹配算法，在 5 毫秒内从您 1600+ 篇便签中过滤并提取出 **最相关的 12 篇历史日记/便签原文**，作为“记忆碎片”注入 DeepSeek 上下文。
*   **上下文范围动态切换**：
    *   `🌍 全量便签`：从 1600+ 篇便签中全局检索最相关的日记作为记忆片段；
    *   `📁 当前分类`：仅在左侧当前选中的分类目录下进行局部匹配；
    *   `📄 当前便签`：将焦点 100% 锁定在右侧当前阅读的单篇便签，支持一键进行深度提炼、概括或问答。
*   **多维度预设人生回顾卡片**：
    *   **🎭 情感心路回顾**：分析您过去几年文字中流露的喜怒哀乐与心理变化；
    *   **🚀 事业成长轨迹**：自动梳理您的技术积累、学习心得与攻克的工作难关；
    *   **🔍 哲学自我追问**：总结您过去对人生理想、幸福与自我的思考和解法；
    *   **✨ 人生高频词提取**：对全量文字做高频词频提炼，精准画出您的人生特征画像。
