# 会话宪法

## 纪律一：每卡必签
每完成一张卡片/子任务，立即执行收尾三步：
1. git commit（语义化英文 message，仅 stage 本任务文件）
2. 更新对应 plan 文档（标记 ✅ done）
3. 更新 PROGRESS.md（做了什么、还差什么、关键决策、下一步）

## 纪律二：感觉沉重则压缩
响应变慢或对话较长时，主动调用 auto_compact 释放 token。

## 纪律三：压缩失败则断点
若 auto_compact 提示无法压缩，立即执行纪律一的收尾三步，然后告知用户开启新会话。零丢失。

## 纪律四：无 TODO/占位符
永不提交 TODO、FIXME、空函数、占位符。未完成的功能不提交。
